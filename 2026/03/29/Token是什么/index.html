Token到底是什么

Token（官方中文译名为“词元”）是模型处理信息的基本单位

Context Window 模型一次能够处理的最大信息量
DeepSeek R1 一次最多能处理12.8万(128K)个Token 它不是12.8万个字也不是12.8个词

Token是怎么生成的？它和字、词之间是什么关系？

先了解“大模型的基本工作原理”
大模型本质上是一个巨大的数学函数，内部全是矩阵运算 输入的是数字，输出的也是数字。
它不理解输入的文字，中间需要一个“翻译官”-Tokenizer

Tokenizer负责编码和解码两个环节

  • 编码：文字 → 数字

    1. 切分：把输入文字切分成一个一个最小的单位，切出来的碎片就叫Token
    2. 映射：会把每一个Token映射为对应的数字，这个数字叫Token ID

  • 解码：数字 → 文字
    映射：把Token ID映射为Token

Token 与 Token ID是一一对应关系，Token是文字，Token ID是数字，所表达的内容是一样的。一句话就变成了一串Token ID列表，然后Tokenizer把它传给模型，模型内部进行运算，吐出来一个Token ID，Tokenizer再次登场将Token ID翻译为Token，解码环节不需要切分，模型每次只给出一个Token，没输出完的话继续输出第二个Token等等。

例如，句子“我喜欢苹果！”可能会被拆分为 ["我", "喜欢", "苹果", "！"] 这4个Token。

Tokenizer的实现算法

  • Unigram
    Google
  • BPE
    OpenAI和Anthropic

BPE的训练过程：大致就是从一堆文章里面能找出哪些文字经常在一起使用，把这些经常一起使用的字合起来作为一个Token。生成两个产物：

  • 词表：记录Token和Token ID的表
  • 合并规则

1个Token ≈ 1.5~2个汉字
1个Token ≈ 4个英文字母或0.75个英文单词
